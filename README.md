# ClaudeProfessor

Recursos en español para aprender a utilizar Claude: guías en PDF, prompts, skills y ejemplos de automatización.

**[Visitar claudeprofessor.page](https://claudeprofessor.page/)**

## Qué contiene este repositorio

El sitio web público de ClaudeProfessor, construido con HTML, CSS y JavaScript. Incluye las páginas de recursos, los documentos descargables y los archivos de las skills.

- `index.html`: portada del sitio.
- `boveda.html`: acceso a los recursos.
- `prompts.html` y `skills.html`: páginas de prompts y skills.
- `pdf/`: guías descargables.
- `skills/`: archivos de las skills.
- `base.css` y `fuentes.css`: estilos compartidos y tipografía.
- `buscar.js` y `copiar.js`: utilidades de búsqueda y copia.

## Consultarlo en local

Es un sitio estático. Desde la carpeta del repositorio puedes servirlo con Python 3:

```bash
python3 -m http.server 8000
```

Abre `http://localhost:8000` en el navegador. No necesita instalar dependencias de Node ni ejecutar una compilación para consultar estas páginas.
